How this calculator works

This is a simplified, planning-stage estimate built on standard SROI principles: discounting outcomes for deadweight (what would have happened anyway) and applying a financial proxy multiplier to approximate non-monetary value such as wellbeing, resilience, and social capital. It is a directional tool to help you scope and communicate impact quickly — not a substitute for a formal SROI assurance process. Mujanti can produce a fully cited, methodologically rigorous SROI report suitable for board or donor use.
